# Postech_FullStack# POSTECH Full Stack - FIAP

Repositório criado para armazenar os estudos, exercícios, desafios e projetos desenvolvidos ao longo da pós-graduação **POSTECH Full Stack** da **FIAP**.

## Objetivo

Este repositório tem como finalidade organizar minha evolução durante o curso, centralizando conteúdos práticos e teóricos relacionados ao desenvolvimento Full Stack, arquitetura de software, boas práticas de programação e construção de aplicações modernas.

## Sobre o curso

O **POSTECH Full Stack da FIAP** é uma formação voltada para o desenvolvimento de soluções completas, abrangendo desde o front-end até o back-end, além de conceitos de arquitetura, integração, banco de dados, APIs, versionamento e boas práticas de mercado.

Ao longo do curso, são explorados temas como:

- Lógica e fundamentos de programação
- Desenvolvimento Front-end
- Desenvolvimento Back-end
- APIs e integrações
- Banco de dados
- Arquitetura de software
- Boas práticas de desenvolvimento
- Versionamento com Git e GitHub
- Projetos práticos
